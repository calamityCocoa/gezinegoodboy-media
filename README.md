# gezinegoodboy-media

Video files for [gezinegoodboy.vercel.app](https://gezinegoodboy.vercel.app), served by GitHub Pages so they come with a proper `video/mp4` type (used for the Discord embed and as a backup player source).

- `asmr.mp4`: gezine's bootstrap.bas ASMR, 720x720 (bootstrap.bas from [pepsipu's ns2jb](https://gitlab.com/pepsipu/ns2jb)). Full quality is on the [gezinegoodboy release](https://github.com/calamityCocoa/gezinegoodboy/releases/tag/asmr).
